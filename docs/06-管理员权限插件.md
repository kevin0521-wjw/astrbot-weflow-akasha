# 06 · 管理员权限插件

## 背景

桥接层是**纯消息中继**，不判断「谁是谁、有没有权限」。所以管理员权限要落在 **AstrBot 侧**——它有成熟的插件体系与权限装饰器。

## 成品

```
astrbot_plugin_admin_manager/
├── main.py          插件实现
└── metadata.yaml    插件元信息
```

打包安装包 `astrbot_plugin_admin_manager.zip`（AstrBot WebUI 支持「从文件安装」）。

## 权限机制（两层）

```python
@filter.permission_type(filter.PermissionType.ADMIN)   # 第一层：AstrBot 框架原生校验
@filter.command("admin add")                           # 第二层：命令路由
```

| 层 | 由谁判定 | 名单在哪 |
|----|----------|----------|
| 第一层 | AstrBot 框架 | **AstrBot WebUI → 设置 → 管理员配置** |
| 第二层 | 插件自身 | 插件目录下的 `admin_users.json`（辅助、可选） |

**关键点**：真正的「管理员是谁」由 **AstrBot 框架** 决定，不在插件里。
所以**必须先把自己加进 AstrBot 的管理员配置**，否则 `/admin add` 会因为无权限而拒绝执行 —— 鸡生蛋问题。

## 指令表

| 指令 | 权限 | 功能 |
|------|------|------|
| `/ping` | 所有人 | 测试连通性，返回发送者 ID 与角色（管理员/普通用户） |
| `/admin` | 仅管理员 | 查看本地管理员列表 |
| `/admin add <wxid>` | 仅管理员 | 添加管理员 |
| `/admin remove <wxid>` | 仅管理员 | 移除管理员 |
| `/reload` | 仅管理员 | 重载本地管理员列表 |

## 安装步骤

1. AstrBot WebUI → **插件管理** → **从文件安装** → 选择 `astrbot_plugin_admin_manager.zip`
   （或解压到 `~/.astrbot/data/plugins/astrbot_plugin_admin_manager/`）
2. 启用插件。
3. **先手动在 AstrBot WebUI → 设置 → 管理员配置 中把自己加进去**（填 wxid 或 session_id）。
4. 在群里发 `/ping` 验证：应返回 `角色: 管理员`。
5. 之后即可用 `/admin add wxid_xxx` 给其他用户授权。

## 发送者标识

```python
def _get_sender_identifier(event: AstrMessageEvent) -> str:
    """获取消息发送者的唯一标识符（优先 wxid，其次 user_id）"""
    sender_id = event.get_sender_id()
    ...
```

微信侧建议用 **wxid** 作为标识（稳定、唯一）；昵称会变、重名，不适合做权限判据。

## 备选：不改代码的极简方案

如果只要「少数几个人能触发管理指令」，其实**不用写插件**，
直接在 AstrBot WebUI → 设置 → 管理员配置 里加人即可 —— AstrBot 内置命令已经认这套名单。
插件只在需要**运行期动态增删 + 列表查询**时才值得上。

## 与白名单的关系

| 机制 | 管什么 | 位置 |
|------|--------|------|
| 群白名单 `id_whitelist` | 哪个**群/会话**能进 AstrBot | AstrBot `cmd_config.json` |
| 管理员 `PermissionType.ADMIN` | 哪个**用户**能执行管理指令 | AstrBot 管理员配置 + 本插件 |

两者互不替代。
